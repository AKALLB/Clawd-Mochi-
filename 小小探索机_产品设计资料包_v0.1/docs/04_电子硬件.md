# 电子硬件

## 系统组成

```text
USB-C 5 V -> RP2040-Zero
                 |-- SPI -> ST7789 屏幕
                 |-- I2C -> GY-521 / MPU6050
                 |-- GPIO <- TTP223
                 |-- PWM -> 无源蜂鸣器驱动
                 |-- GPIO -> 静音开关
                 `-- GP16 -> 板载 WS2812
```

RP2040 的 GPIO 为 3.3 V 逻辑，不得接入 5 V 信号。GY-521 使用 3.3 V 供电，
避免其 I2C 上拉到 5 V。

## 建议引脚分配

| RP2040-Zero | 功能 | 连接对象 |
| --- | --- | --- |
| GP0 | I2C SDA | GY-521 SDA |
| GP1 | I2C SCL | GY-521 SCL |
| GP2 | SPI SCK | ST7789 SCL/SCK |
| GP3 | SPI MOSI | ST7789 SDA/MOSI |
| GP5 | 屏幕 CS | ST7789 CS |
| GP6 | 屏幕 DC | ST7789 DC |
| GP7 | 屏幕 RST | ST7789 RES/RST |
| GP8 | 背光控制预留 | 经模块适配电路连接 BLK |
| GP9 | 触摸输入 | TTP223 OUT |
| GP10 | 蜂鸣器 PWM | 经 1 kΩ 电阻连接 NPN 驱动 |
| GP11 | 静音输入 | 开关对 GND，使用内部上拉 |
| GP16 | 板载 RGB | RP2040-Zero 板载 WS2812 |

不同 ST7789 小板可能没有 CS、RST 或独立背光控制。购买具体模块后，应按卖家
原理图和实测结果更新表格，禁止仅按丝印颜色接线。

## 模块要求

### GY-521 / MPU6050

- 购买已焊弯针版，使线束从侧面走向后盖。
- 只连接 VCC、GND、SCL、SDA，XDA/XCL/AD0/INT 在 v0.1 中不使用。
- 弯针朝后盖或托盘走线侧，不朝向屏幕。
- 固定时不要让螺丝或支架压到元件。

### ST7789 屏幕

- 分辨率必须为 240 x 240，SPI 接口，3.3 V 逻辑兼容。
- 下单前确认“1.54 英寸”指显示尺寸，而非仅商品标题。
- 记录 PCB 外形、可视区偏移、排针数量和背光接法。
- 屏幕表面增加透明 PET 保护片，边缘不得锐利。

### TTP223

- 感应面贴近顶部薄壁，先用 1.2、1.4、1.6 mm 试片验证。
- 导线与屏幕排线分开布置，降低干扰。
- 固件上电后留出稳定时间，并做触摸去抖。

### 无源蜂鸣器

- 选择支持 3.3 V 控制的无源蜂鸣器模块，或使用 S8050/NPN 加 1 kΩ 基极电阻
  驱动裸蜂鸣器。
- 不从 GPIO 直接驱动未知电流的蜂鸣器。
- 加物理静音开关，音量以教室近距离不刺耳为准。

## 线束

学生只进行插接和布线，教师预先完成焊接。建议使用 JST-PH 2.0：

- 4 芯：GY-521。
- 3 芯：TTP223。
- 2 芯：蜂鸣器和静音开关。
- 屏幕根据最终引脚数使用带键位多芯插头。

所有插头两端贴相同编号，电源线固定红色为 3.3 V、黑色为 GND。不得依赖插头
外壳颜色判断极性。
