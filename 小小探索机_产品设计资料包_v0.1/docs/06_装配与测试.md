# 装配与测试

## 角色分工

- 教师：焊接排针与线束、检查极性、首次通电、烧录和故障处理。
- 学生：识别模块、插接 JST-PH、固定模块、整理线束、安装外壳并执行测试。

学生不得在设备通电时插拔线束。

## 教师预装

1. 核对每个模块的型号、引脚丝印和供电电压。
2. 给 GY-521 焊接弯针，弯针方向与托盘走线方向一致。
3. 制作有防反插方向的 JST-PH 线束，并逐线做通断测试。
4. 焊接蜂鸣器驱动电路和静音开关。
5. 在无外壳状态下完成分模块测试。
6. 限流电源首次上电；确认无异常发热后再接普通 USB 电源。

## 学生装配

1. 断开 USB-C。
2. 将屏幕装入屏幕框，确认可视区居中且无受压。
3. 将 RP2040-Zero、GY-521、TTP223 和蜂鸣器固定到简化托盘。
4. 按编号插入线束，检查红色 3.3 V 和黑色 GND。
5. 让 GY-521 弯针朝后盖走线侧，线束不得顶住屏幕。
6. 用扎带孔整理余线，保留插头拆卸余量。
7. 将托盘装入主体，确认 USB-C 插头可正常插拔。
8. 合上后盖，四颗 M2 螺丝对角逐步拧紧，禁止过度用力。

## 单机验收

| 项目 | 方法 | 通过标准 |
| --- | --- | --- |
| 外观 | 目视和手摸 | 无锐边、裂缝、明显翘曲 |
| USB-C | 插拔 10 次 | 不顶壳、不松动、不断电 |
| 屏幕 | 显示测试图 | 无明显错位、闪屏或压痕 |
| 触摸 | 轻触 20 次 | 成功率至少 19/20，无连续误触 |
| 姿态 | 左右倾斜各 10 次 | 方向正确，稳定放置不乱跳 |
| 蜂鸣器 | 播放四种反馈 | 声音清楚、不刺耳，静音有效 |
| RGB | 显示红绿蓝白 | 颜色正确，顶部可见不过亮 |
| 休眠 | 缩短计时测试 | 可进入并通过两种方式唤醒 |
| 线束 | 轻晃整机 | 无重启、花屏或接触不良 |
| 温升 | 运行 30 分钟 | 外壳无明显烫手区域 |

## 常见故障

| 现象 | 优先检查 |
| --- | --- |
| 完全不亮 | USB 线、电源、主板 5 V/GND 是否短路 |
| 屏幕白屏 | SPI 引脚、DC/RST、驱动尺寸和偏移 |
| 姿态无数据 | GY-521 是否 3.3 V、SDA/SCL 是否接反、I2C 地址 |
| 倾斜方向相反 | 模块安装朝向或固件轴映射 |
| 触摸乱跳 | 顶部厚度、线长、接地、与屏幕线束距离 |
| 蜂鸣器无音 | 是否为无源型号、驱动三极管、静音开关 |
| 合盖后故障 | 插头受压、螺丝碰线、线束弯折过紧 |

测试中发现焦味、冒烟、异常高温或反复掉电时，立即断开 USB，不继续尝试。
