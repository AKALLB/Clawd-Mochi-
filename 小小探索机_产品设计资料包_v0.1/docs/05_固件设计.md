# 固件设计

## 技术方案

- 框架：Arduino C++，RP2040 Arduino Core。
- 屏幕：使用与最终 ST7789 模块兼容的图形库。
- 姿态：I2C 读取 MPU6050，v0.1 主要使用加速度，不依赖陀螺仪积分。
- 图形文字：表情图元、天气图标和少量固定中文字模，不加载完整中文字库。
- 数据：不联网、不记录用户身份、不持久化心情。

在硬件到货和引脚验证前，不锁定第三方库版本，也不发布声称可用的固件成品。

## 状态机

```text
BOOT -> SELF_TEST -> IDLE
IDLE -> MOOD_SELECT       长触约 2 秒
MOOD_SELECT -> MOOD_REPLY 轻触确认
MOOD_REPLY -> IDLE        约 5 秒
IDLE -> DIM               空闲 3 分钟
DIM -> SLEEP              空闲 10 分钟
DIM/SLEEP -> IDLE         触摸或拿起
BOOT -> DEMO              通电时持续触摸约 3 秒
DEMO -> IDLE              长触约 2 秒
任意状态 -> ERROR         关键外设初始化或运行异常
```

## 模块边界

| 模块 | 职责 |
| --- | --- |
| `input_touch` | 触摸去抖、短触和长触事件 |
| `input_motion` | 加速度采样、稳定判断、拿起和倾斜事件 |
| `ui_display` | 表情、天气选项、固定中文和故障图标 |
| `output_light` | WS2812 颜色、亮度和关闭 |
| `output_sound` | 音符序列、音量时长限制和静音 |
| `app_state` | 状态机、计时和事件分发 |
| `diagnostics` | 上电自检和教师演示数据 |

各输入模块只产生事件，不直接切换界面；状态机决定输出，便于课堂讲解和测试。

## 初始参数

- 传感器采样周期：20 ms。
- 触摸去抖：50 ms。
- 长触阈值：2000 ms。
- 倾斜保持：250 ms。
- 拿起动作确认：150 ms。
- 姿态稳定确认：1000 ms。
- 回复停留：5000 ms。
- 降亮：180000 ms。
- 休眠：600000 ms。

以上均为可配置常量，实机测试后调整。

## 异常处理

- I2C 超时不得阻塞主循环；重试失败后进入降级模式。
- MPU6050 失效时关闭倾斜选择，允许触摸循环选择天气。
- 屏幕失效时用 RGB 错误码提示，蜂鸣器不持续报警。
- 触摸持续有效超过 15 秒时视为卡住，忽略到释放。
- 使用无阻塞计时，不用长时间 `delay()`。
- 看门狗启用前先验证显示库和 I2C 操作不会造成误复位。

## 验收功能

- 冷启动 3 秒内进入待机。
- 四种天气均可通过倾斜选择并确认。
- 静音开关在任何状态立即阻止新声音。
- 连续交互 20 次不死机。
- 断开 GY-521 后能显示故障并继续响应触摸。
- 休眠后通过触摸和拿起均能恢复。
