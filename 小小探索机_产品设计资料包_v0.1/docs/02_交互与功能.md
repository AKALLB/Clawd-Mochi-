# 交互与功能

## 日常状态

设备通电后先显示启动表情并进行硬件自检，随后进入待机。待机时显示呼吸感
表情，板载 RGB 以低亮度缓慢变化，蜂鸣器保持静音。

| 输入 | 判定建议 | 输出 |
| --- | --- | --- |
| 拿起 | 加速度幅值明显变化并持续约 150 ms | 眨眼、短音、灯光响应 |
| 轻触顶部 | TTP223 有效 50-800 ms | 表情回应或确认当前选项 |
| 长触顶部 | 持续约 2 s | 进入心情天气选择 |
| 左右倾斜 | 横向加速度越过阈值并保持约 250 ms | 切换天气选项 |
| 放回桌面 | 姿态稳定约 1 s | 回到安静待机 |

所有时间和阈值均为固件初始值，应在实机上调整。

## 心情天气仪式

1. 长触顶部约 2 秒，设备显示“现在像什么天气？”。
2. 左右倾斜依次选择：
   - 晴朗·开心
   - 微风·平静
   - 阴天·低落
   - 雷雨·烦躁
3. 轻触确认。
4. 设备以表情、颜色和一段不超过 2 秒的非语言音效回应。
5. 约 5 秒后回到待机，不保存历史记录。

回应文案保持中性，例如“收到”“陪你待一会儿”。不得出现“只有我懂你”
“不要离开我”等依赖性表达，也不根据选择对学生进行评分。

## 灯光与声音

| 天气 | 建议颜色 | 声音方向 |
| --- | --- | --- |
| 晴朗 | 暖黄 | 上扬双音 |
| 微风 | 青绿 | 柔和单音 |
| 阴天 | 蓝灰 | 缓慢低音 |
| 雷雨 | 紫红 | 短促两音后安静 |

RGB 亮度默认不超过可用范围的 20%，蜂鸣器不播放语言或尖锐长音。后盖设置
物理静音开关；静音只关闭蜂鸣器，不影响屏幕和灯光。

## 休眠与唤醒

- 无操作 3 分钟：降低屏幕和 RGB 亮度。
- 无操作 10 分钟：关闭 RGB，并让显示进入睡眠；若具体屏幕模块的背光可控，
  同时关闭背光。
- 触摸或明显拿起动作：唤醒并恢复待机。
- USB 重新上电：重新启动，不恢复上次心情。

本机没有 RTC，不能可靠判断“每天一次”，因此不设置每日签到。

## 教师演示模式

通电时按住顶部触摸区约 3 秒进入演示模式。屏幕循环显示：

- X/Y/Z 三轴加速度的简化条形图。
- 当前倾斜方向。
- 触摸输入状态。
- RGB、屏幕和蜂鸣器输出测试。
- “输入 -> 判断 -> 输出”流程。

长触约 2 秒退出演示模式。演示模式不写入存储器。

## 误触与异常

- 对触摸和倾斜使用时间去抖，单次动作只触发一次。
- 震动过强时暂停选项切换，待姿态稳定后继续。
- MPU6050 无响应时显示传感器故障图标，触摸和屏幕功能仍可使用。
- 屏幕初始化失败时用 RGB 三次红闪提示，不持续鸣叫。
