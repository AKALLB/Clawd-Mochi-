# 建模检查表

## 建模前

- [ ] 已使用最新版电子模块占位体。
- [ ] 已确认外包络仍为本轮课程规定尺寸。
- [ ] 已标出屏幕可视区、USB-C 和四个后盖螺丝基准。
- [ ] 已确定打印方向。

## 主体

- [ ] 用基础实体和圆角完成，无不必要复杂曲面。
- [ ] 壁厚满足结构尺寸规范。
- [ ] 屏幕窗口对准可视区，不以 PCB 边缘代替可视区。
- [ ] 背面完全敞开，可装入托盘。
- [ ] 顶部信号结构无易折断细杆。
- [ ] 触摸区和 RGB 透光区厚度经过试片验证。

## 屏幕框

- [ ] 由两个圆角矩形相减得到。
- [ ] 能遮住 PCB 和保护片边缘。
- [ ] 不挤压屏幕玻璃或排线。
- [ ] 平放打印时不需要支撑。

## 托盘

- [ ] 仅包含 L 形主体、必要支撑、固定孔和两个扎带孔。
- [ ] 所有模块占位体无相交。
- [ ] 插头有插拔空间，线束有转弯空间。
- [ ] GY-521 弯针朝后盖走线侧。
- [ ] 托盘可整体装入和取出。

## 后盖

- [ ] 四个 M2 孔与主体螺丝柱同轴。
- [ ] USB-C 插头可完整插入并可用手拔出。
- [ ] 静音开关可操作且不会被误碰。
- [ ] 蜂鸣器出声孔无尖角。
- [ ] 后盖内侧不压迫线束或元件。

## 打印前

- [ ] 所有零件均为封闭实体，无反法线或悬空碎片。
- [ ] 模型单位为毫米。
- [ ] 主体、屏幕框、托盘和后盖已分别导出。
- [ ] 切片预览中壁厚、孔洞和首层连续。
- [ ] 支撑只出现在确有必要的位置。
- [ ] 文件名包含部件名和版本号。

## 装配后

- [ ] 配合不过松也不过紧。
- [ ] 四颗螺丝可对角锁紧。
- [ ] 摇晃设备无零件撞击声。
- [ ] 可在不破坏外壳的情况下拆换模块。
- [ ] 已记录需要修改的尺寸及原因。
