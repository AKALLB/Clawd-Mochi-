# 淘宝单件采购说明

## 预算

- 常见单件物料合计：约 70-119 元。
- 考虑店铺起售数量和多店运费，实际付款通常约 100-160 元。
- 建议准备 150 元。
- 若同时购买一块备用屏幕，建议准备 170-190 元。
- 不包含 3D 打印材料、工具、焊锡和打印服务。

价格会随店铺、运费和活动变化，BOM 中的数字只用于原型预算。

## 下单顺序

1. 先购买 RP2040-Zero 和 ST7789 屏幕。
2. 再购买 GY-521、TTP223、蜂鸣器和开关。
3. 模块到货后实测引脚和尺寸。
4. 根据最终布局确定 JST-PH 线长、芯数和插头方向。
5. 最后购买螺丝、保护片和线束耗材。

## 屏幕辨别

同为“1.54 英寸 ST7789”的商品可能有不同 PCB 和引脚：

- 确认分辨率为 240 x 240，不购买 240 x 320。
- 确认 SPI 接口，不购买并口版本。
- 向卖家索取引脚定义和外形尺寸图。
- 优先选择明确支持 3.3 V 逻辑的模块。
- 确认是否有 `CS`、`RST`、`BLK`，不要仅看商品主图。
- 不在屏幕到货前制作最终屏幕框。

## GY-521 选择

购买**已焊弯针版**。弯针让 JST-PH 线束从侧面进入，可降低厚度并避免后盖
压线。使用 3.3 V 供电，只接 `VCC/GND/SCL/SDA`。

## 到货检查

每种模块先拍摄正反面并记录：

- PCB 最大长、宽、厚。
- 安装孔直径与孔中心距。
- 接口、排针和最高元件高度。
- 屏幕可视区及相对 PCB 的偏移。
- USB 插头插入后的总长度和弯线空间。
- 丝印引脚与卖家资料是否一致。

用万用表检查线束通断和相邻端子短路。首次上电由教师完成，出现异常发热立即
断电并联系卖家。
