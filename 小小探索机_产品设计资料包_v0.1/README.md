# 小小探索机

面向 9-12 岁学生的离线桌面互动宠物与科创课程原型。

本仓库记录单件功能原型的产品、结构、电子、固件和课程设计。它不是量产
图纸、医疗器械、心理治疗工具或已经通过认证的商品。

## 核心体验

- 拿起设备时，通过姿态变化给出表情、灯光和短音反馈。
- 长触顶部触摸区进入心情记录，倾斜选择，轻触确认。
- 用“晴朗、微风、阴天、雷雨”等天气隐喻帮助学生表达当下感受。
- 完全离线运行，不采集语音、图像、位置或账号信息。
- 教师可进入演示模式，展示传感器、状态机和人机交互原理。

## 原型硬件

| 模块 | 选型 |
| --- | --- |
| 主控 | Waveshare RP2040-Zero |
| 显示 | 1.54 英寸 ST7789，240 x 240，SPI |
| 姿态 | GY-521 / MPU6050，弯针版，3.3 V 供电 |
| 触摸 | TTP223 电容触摸模块 |
| 声音 | 无源蜂鸣器及驱动电路 |
| 灯光 | RP2040-Zero 板载 WS2812 |
| 供电 | USB-C 有线供电，无电池 |

计划整机外包络为 `80 x 68 x 88 mm`。该尺寸是建模起点，不是生产尺寸；
购买模块并实测后才可冻结 CAD。
