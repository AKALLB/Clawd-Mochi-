# 项目概览

## 这个东西是什么
Clawd Mochi 是一个实体桌面小宠物/摆件。它用 ESP32-C3 SuperMini 作为主控，用 1.54 英寸 ST7789 240×240 SPI 屏幕显示表情和小动画，再用 3D 打印外壳做成 Claude Code 像素螃蟹 Clawd 风格。

## 它能做什么
- 显示普通眼睛动画：方块眼睛、左右晃动、眨眼。
- 显示 Squish eyes：`> <` 风格开心眯眼。
- 显示 Claude Code 界面。
- Canvas 画板模式：手机连上它的 WiFi 后，可以在网页里画图并显示到屏幕上。
- 网页控制：不需要 App，不需要云端，不需要连接互联网。

## 基本工作原理
1. ESP32-C3 通电启动。
2. ESP32-C3 通过 SPI 协议驱动 ST7789 TFT 屏幕。
3. ESP32-C3 创建一个 WiFi 热点，例如 `ClaWD-Mochi`。
4. 手机或电脑连接这个热点。
5. 浏览器访问 `http://192.168.4.1`。
6. 网页按钮向 ESP32 发送命令，ESP32 根据命令刷新屏幕内容。

## 技术栈
- 硬件：ESP32-C3 SuperMini、ST7789 TFT 屏幕、杜邦线、3D 打印外壳。
- 固件：Arduino C/C++。
- 显示库：Adafruit GFX、Adafruit ST7735 and ST7789。
- 网络：ESP32 WebServer + SoftAP 热点。

## 难度评估
- 采购难度：低。
- 接线难度：低到中，重点是别接错电源。
- 焊接难度：低；可以先用杜邦线测试，稳定后再焊接。
- 3D 打印难度：低到中，需要支持结构。
- 软件烧录难度：中，主要坑在 ESP32-C3 板型和 USB CDC 设置。

## 工程目标
完成后应该得到：一个 USB-C 供电的小桌面宠物，手机连接它的 WiFi 后可以控制屏幕表情。
