# Clawd Mochi（Claude Code 小宠物）工程资料包

本资料包面向“从未做过这个项目的工程师/学生”，目标是从零采购、接线、烧录、3D 打印、装配并排查问题。

## 项目一句话说明
Clawd Mochi 是一个开源实体桌面小宠物：使用 ESP32-C3 SuperMini 驱动 1.54 英寸 240×240 ST7789 彩色屏幕，外壳为 3D 打印小螃蟹造型，通电后可通过它自己的 WiFi 热点和网页控制表情、Claude Code 画面、画板等。

## 推荐完成路径
1. 先读 `01_项目说明/项目概览.md`
2. 按 `02_采购清单/BOM采购清单.csv` 买材料
3. 按 `03_接线与硬件/接线表.md` 接线，特别注意 VCC 只能接 3.3V
4. 按 `04_软件烧录/Arduino_IDE_烧录步骤.md` 安装 Arduino 环境并烧录
5. 按 `05_3D打印外壳/3D打印说明.md` 打印外壳
6. 按 `06_装配测试/装配流程.md` 装配
7. 不亮、不显示、连不上 WiFi，就看 `07_故障排查/常见问题.md`
