# 装配流程

## 阶段 A：桌面裸机测试
1. 不装外壳，先把 ESP32-C3 和屏幕接好。
2. 烧录 `09_示例代码/01_display_test/01_display_test.ino`。
3. 屏幕能显示颜色和文字后，再烧录正式代码。
4. 连接 WiFi 热点，确认网页能打开。

## 阶段 B：整理线材
1. 如果使用杜邦线，尽量换成短线。
2. 如果准备长期使用，建议焊接。
3. 焊接后用热缩管或胶带做绝缘。
4. 用万用表确认 3V3 和 GND 没短路。

## 阶段 C：装入外壳
1. 先把屏幕放入外壳窗口，确认方向正确。
2. 用 M2×6mm 螺丝固定屏幕，别拧太紧。
3. 把 8 根线从背板槽位走线。
4. 用双面胶固定 ESP32-C3。
5. USB-C 口朝向背板开孔，方便插线。
6. 合上背板前最后通电测试一次。

## 阶段 D：最终测试
- 通电 3 秒后屏幕有显示。
- 手机能搜到 `ClaWD-Mochi`。
- 密码 `clawd1234` 能连接。
- 浏览器打开 `http://192.168.4.1`。
- Normal eyes、Squish eyes、Claude Code、Canvas 按钮能正常切换。
- 背光开关有效。
