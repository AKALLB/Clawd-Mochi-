# 接线表

⚠️ 最重要：屏幕 VCC 只接 ESP32-C3 的 3V3，不要接 5V。

| ST7789 屏幕引脚 | ESP32-C3 SuperMini 引脚 | 说明 | 建议线色 |
|---|---|---|---|
| VCC | 3V3 | 屏幕供电 | 红色 |
| GND | GND | 地线 | 黑色 |
| SDA | GPIO 10 | SPI MOSI | 橙色 |
| SCL | GPIO 8 | SPI SCK | 绿色 |
| RES / RST | GPIO 2 | 屏幕复位 | 紫色 |
| DC | GPIO 1 | 数据/命令选择 | 蓝色 |
| CS | GPIO 4 | 片选 | 白色 |
| BL / BLK | GPIO 3 | 背光控制 | 黄色 |

## 不建议使用的引脚
原项目说明中提醒不要用 GPIO 6/7 做 SPI。它们在某些 ESP32-C3 板子上可能与 Flash 或内部功能冲突。

## 接线检查顺序
1. 先接 VCC 和 GND。
2. 再接 SDA、SCL。
3. 再接 RES、DC、CS。
4. 最后接 BL。
5. 通电前用万用表检查 VCC 没有接到 5V。

## 常见屏幕引脚别名
- SDA = MOSI = DIN
- SCL = SCK = CLK
- RES = RST = RESET
- BL = BLK = LED = Backlight
