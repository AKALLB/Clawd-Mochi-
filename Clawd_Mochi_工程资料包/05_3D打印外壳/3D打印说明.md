# 3D 打印外壳说明

## 官方模型
原项目的电子外壳模型文件在仓库中的：
```text
models/clawd_mochi/clawd_mochi_v1.stl
```
也可在 MakerWorld 下载官方模型。链接见 `08_参考资料/原项目下载链接.md`。

## 推荐打印参数
| 参数 | 推荐值 |
|---|---|
| 材料 | PLA 或 PETG |
| 层高 | 0.15–0.20 mm |
| 填充 | 15% gyroid |
| 支撑 | 需要，尤其是屏幕窗口悬垂位置 |
| 朝向 | 正面朝下，平背面贴打印平台 |
| 颜色 | 橙色外壳，黑色背板更接近原效果 |

## 打印前检查
1. 确认屏幕尺寸为 1.54 英寸 240×240。
2. 确认屏幕 PCB 尺寸能放入外壳。
3. 先低质量打印一个测试件，试装屏幕。
4. 确认 USB-C 线能从背板开孔处穿出。

## 没有 3D 打印机怎么办
- 找淘宝/闲鱼/本地 3D 打印服务。
- 把 STL 文件发给打印店。
- 备注材料 PLA、颜色橙色、层高 0.2 mm、需要支撑。
