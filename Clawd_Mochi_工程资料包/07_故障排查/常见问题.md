# 常见问题与排查

## 1. 屏幕完全不亮
可能原因：
- VCC/GND 接反或没接好。
- BL 背光脚没接。
- 屏幕坏了。
- VCC 接错到不稳定电源。

处理：
1. 确认 VCC → 3V3，GND → GND。
2. 确认 BL → GPIO3。
3. 用最小测试代码让 GPIO3 输出 HIGH。
4. 换一块屏幕或一块 ESP32-C3 交叉测试。

## 2. 屏幕亮但没有图像
可能原因：
- SDA/SCL 接反。
- DC/CS/RST 接错。
- 屏幕不是 ST7789。
- 代码里引脚定义和实际接线不一致。

处理：
1. 对照接线表逐根检查。
2. 屏幕 SDA 接 GPIO10，SCL 接 GPIO8。
3. 检查屏幕驱动芯片是否 ST7789。
4. 先烧录 display_test。

## 3. Arduino 上传失败
可能原因：
- USB 线只是充电线。
- 没选对开发板或串口。
- USB CDC On Boot 没开。
- 板子进入下载模式失败。

处理：
1. 换一根可传数据 USB-C 线。
2. Board 选 ESP32C3 Dev Module。
3. USB CDC On Boot 设 Enabled。
4. 上传时按住 BOOT，再点 Upload；出现连接后松开。

## 4. 手机搜不到 WiFi
可能原因：
- 没烧录正式 WiFi 代码。
- ESP32 程序崩溃重启。
- 电源不足。

处理：
1. 打开串口监视器看是否启动。
2. 使用 5V 1A 以上 USB 供电给 ESP32 板子。
3. 烧录本包 `02_wifi_display_test` 验证热点。

## 5. 能连 WiFi，但打不开网页
处理：
1. 确认手机没有自动切回移动网络。
2. 浏览器手动输入 `http://192.168.4.1`。
3. 不要输入 https。
4. 关闭手机的“智能切换网络/无线局域网助理”。

## 6. 装进外壳后变得不稳定
可能原因：
- 线材被压住。
- 杜邦线松动。
- USB-C 口受力。

处理：
1. 改用短线焊接。
2. 用热熔胶固定线材。
3. 确保背板闭合时不压屏幕排针。
